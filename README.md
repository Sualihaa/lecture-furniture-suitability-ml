# Lecture Furniture Suitability Prediction Using Elastic-Net Regularized Logistic Regression

This repository contains code and workflows for predicting lecture furniture suitability using an elastic-net regularized logistic regression model.

The project explores how machine learning techniques can support ergonomic and human-factor assessments in educational environments.

---

## Objectives

- Develop a predictive model for lecture furniture suitability
- Explore elastic-net regularization for feature selection
- Evaluate classification performance
- Investigate ergonomic predictors of suitability

---

## Methods

- Logistic Regression
- Elastic-Net Regularization
- Cross-Validation
- Feature Scaling
- Classification Metrics
